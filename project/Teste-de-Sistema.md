# Testes de Sistema 

Os testes de sistema verificam o funcionamento integrado do ORÁCULO, incluindo a compilação, a inicialização, a movimentação da personagem, a exibição dos sprites e as funcionalidades implementadas na Sprint 01.

Os testes foram executados para validar os comportamentos esperados. Os screencasts de evidência ainda serão produzidos e deverão ser anexados aos cards correspondentes no Board.

| ID | Caso de Teste | Resultado Esperado | Status |
|---|---|---|---|
| TS01 | Compilar Projeto com CMake | Projeto compilado sem erros. | Aprovado |
| TS02 | Iniciar Executável | Janela do jogo aberta corretamente. | Aprovado |
| TS03 | Movimentar Personagem | Personagem responde aos comandos de movimentação implementados. | Aprovado |
| TS04 | Alternar Sprites Idle e Walk | Sprites correspondem ao estado da personagem. | Aprovado |
| TS05 | Executar Histórias Implementadas | Funcionalidades apresentam os comportamentos esperados. | Aprovado |
| TS06 | Encerrar Jogo | Aplicação encerrada corretamente. | Aprovado |
